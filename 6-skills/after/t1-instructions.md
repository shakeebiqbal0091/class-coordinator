# T1 instructions: the Friday list

Use these instructions for T1 of the Class Coordinator for Class 7B. T1 has two runs. Run 1 makes the Friday list, every Friday. Run 2 makes email drafts about that list, when Ms. Khan asks.
The rules for every task are in the project instructions. This file adds the rules and the steps of T1.
Every name in this file is invented.

## Rules for T1

- The list date is the most recent Friday: today, if today is a Friday.
- An assignment is pending when its due date is before the list date, and the Submitted column says "No". This is rule 2 of the class rules.
- Homework due on the list date, and not submitted, goes under the heading "Due today, not counted". It is not pending. It is in no draft.
- A row with an empty cell, or a date or a Submitted value that is not clear, goes under the heading "Needs your check". Never guess.
- The list goes in a new tab named "Pending <list date>" in the work record, for example "Pending 2026-11-20".
- The matter is "Friday list <list date>". Every Log row of T1 has Task "T1" and this matter.
- Draft an email only when Ms. Khan asks, and only for a roll number on the newest list: the newest tab named "Pending YYYY-MM-DD".
- One draft for each roll number. It says only the pending assignments and their due dates.
- Never read email.

## Run 1: the Friday list

1.1 Start. Work out the list date. Start the run with the skill start-and-end-a-run, for the matter "Friday list <list date>". If Ms. Khan asked for the list in the project, the Started row adds: "Ms. Khan asked for the list."
- If a Done row says that the tab is made, add a Completed row: "T1 run <start time> completed: list already made, see row N." Say so, and end.
- If the skill found an earlier run that stopped, look in the work record for the tab "Pending <list date>". If the tab is there, it may be half made: add a Needs Ms. Khan row ("Check the tab Pending <list date>: an earlier run stopped"), then a Completed row ("nothing made"), and end. If there is no tab, go on.

1.2 Check the working copy with the skill check-the-working-copy: the Homework tab, with the headings Roll number, Assignment, Due date and Submitted.

1.3 Read rule 2 of the class rules. Put each Homework row in one group:
- Due date before the list date, and Submitted "No": pending.
- Due date on the list date, and Submitted "No": due today, not counted.
- Due date after the list date, or Submitted "Yes": not on the list.
- Any cell empty or not clear: needs your check.

1.4 Make the list: one line for each pending row, in order of roll number, with the columns Roll number, Assignment, Due date. Count the lines. Check that no line has a due date on or after the list date. Read the Log rows of the matter again: if a Done row for the tab is there now, add a Completed row ("list already made, see row N"), and end. If not, add the tab "Pending <list date>" to the work record. Write "Needs your check" and its rows (or "None"), then "Pending" and the list, then "Due today, not counted" and its lines (or "None"). Add a Done row: "Tab Pending <list date> added: N lines. Due today, not counted: K lines. Needs your check: M rows." Then end the run with the skill start-and-end-a-run, with the count "list made". Report the number of lines and the rows under "Needs your check".

## Run 2: the drafts

1.5 (Ms. Khan) She reviews the list, and asks for drafts by roll number, for example: "Draft emails for 7B-03 and 7B-08."

1.6 Start the run with the skill start-and-end-a-run, for the matter of the newest list. The Started row adds: "Ms. Khan asked for drafts for <roll numbers>." Check the working copy with the skill check-the-working-copy: the Students tab, with the headings Roll number, Student email and Parent email. Then, for each roll number she gives, check two things (the skill save-a-draft-to-a-parent checks the parent email):
- It is on the newest list.
- The Log has no Done row for a draft for this roll number in this matter.
If one check fails, draft nothing for it. Add a Needs Ms. Khan row with the roll number and the reason: "No draft: not on the newest list" or "No draft: already drafted, see row N". Tell her.
If an earlier draft run in this matter has a Started row and no Completed row, it stopped. Drafts are made in the order Ms. Khan gave. The first roll number of that run with no Done row may have a half-made draft: draft nothing for it, and add a Needs Ms. Khan row: "Check your Gmail drafts for this roll number."

1.7 For each roll number that passed, write the draft below with the skill save-a-draft-to-a-parent. The Done row says: "Draft saved in Gmail, to the parent: <assignment>." Next: "Ms. Khan reviews and sends (1.8)". When every roll number has a Done row or a Needs Ms. Khan row, end the run with the skill start-and-end-a-run, with the counts "X drafts, Y need Ms. Khan". Report which drafts were made, and which were not, with the reason.

1.8 (Ms. Khan) She reviews each draft, writes the name, adjusts it if needed, and sends it.

## The draft

To: the parent email for that roll number
Subject: Pending homework: <roll number>

Dear parent of [student name],

The <assignment> was due on <due date>. We have not received it yet. Please help [student name] to finish it and hand it in.

Ms. Ayesha Khan, class teacher of Class 7B

If the roll number has more than one pending assignment, list each assignment and its due date in the same draft. Never put a line from "Due today, not counted" in a draft.
