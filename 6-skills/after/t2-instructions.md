# T2 instructions: the progress notes

Use these instructions for T2 of the Class Coordinator for Class 7B: once a month, on the last Friday for notes, to draft one progress note for each student; and when Ms. Khan asks: "Draft the missing notes."
The rules for every task are in the project instructions. This file adds the rules and the steps of T2.
Every name in this file is invented.

## Words used in this file

- **Ms. Khan's note**: her short text about one student, in the Notes tab. Only she writes it.
- **Progress note**: the email draft to the parent. You write it. It holds the homework of the month and Ms. Khan's note.
- **The last Friday for notes**: the Friday when the notes of a month are made. It is the last Friday of the month. In December, it is the last Friday of the term (the brief gives the date), because the last Friday of December is after the term ends. The brief has the date check.

## Rules for T2

- The matter is "Progress notes YYYY-MM", with the month the notes are for. Every Log row of T2 has Task "T2" and this matter. Add rows as the project instructions say.
- "This month's assignments" are the assignments with a due date in the month of the notes, on or before the last Friday for notes of that month. Use that Friday in place of "today", also when Ms. Khan asks on a later day.
- Facts about homework come only from the Homework tab.
- Ms. Khan writes her note about each student. Never write a note yourself. Never add a word about the student. Copy her note word for word.
- If a homework row has an empty or unclear cell, never guess. Write "[Ms. Khan: please check this assignment]" in place of the empty value, and put a "Check:" line at the top of the progress note.
- Every progress note has the same parts, in the same order (see "The progress note").
- Ms. Khan's only request for T2 is "Draft the missing notes". Then draft each roll number that has no Done row in this matter.
- Never read email.
- The working copy is read-only for you. (A connector setting works for each tool, not for each sheet, so this rule is written here and Ms. Khan checks it.) You add rows only to the Log in the work record.

## Steps

The step numbers are the same as in the Role Contract. Steps 2.1 and 2.9 are Ms. Khan's.

2.1 (Ms. Khan) By Thursday, she writes one short note about each student in the Notes tab, by roll number. The column heading names the month, for example "Ms. Khan's note for November". Her note is about the student as a person. It has no homework facts and no health information. That Thursday, as every Thursday, she also checks the working copy and writes the date in the Updated tab.

2.2 Start. Note today's date and the matter. Start the run with the skill start-and-end-a-run, for this matter. If Ms. Khan asked "Draft the missing notes", the Started row adds: "Ms. Khan asked: Draft the missing notes."
- If this matter has a Completed row, and Ms. Khan did not ask for the missing notes, the notes are already made. Add a Completed row: "T2 run <start time> completed: notes already made, see row N." Say so, and end.
- Draft only for roll numbers that have no Done row in this matter. Draft in order of roll number.
- If an earlier run has a Started row and no Completed row, it stopped. The first roll number after its last Done row may have a half-made draft: draft nothing for it, and add a Needs Ms. Khan row: "Check your Gmail drafts for this roll number." Draft the other roll numbers that have no Done row.

2.3 Check the working copy with the skill check-the-working-copy: the Homework tab, with the headings Roll number, Assignment, Due date and Submitted.

2.4 Read the Notes tab. Check that the heading is "Ms. Khan's note for <month>", with the month of the notes. If not, make no drafts, add a Needs Ms. Khan row ("The Notes tab is not for this month"), then a Completed row ("nothing made"), and end. For a roll number with no note, draft nothing. Add a Needs Ms. Khan row: "No note for this roll number".

2.5 For each roll number with a note, list this month's assignments, with the due date and "submitted" (Submitted is "Yes") or "not submitted" (Submitted is "No"). A row with an empty or unclear cell stays on the list, with "[Ms. Khan: please check this assignment]" in place of the empty value. It also gets a Check line, for example "Check: English reading log has no due date."

2.6 Check the working copy with the skill check-the-working-copy: the Students tab, with the headings Roll number, Student email and Parent email.

2.7 For each roll number with a note, write the progress note below with the skill save-a-draft-to-a-parent. The Done row says: "Draft saved in Gmail, to the parent.", with any Check lines. Next: "Ms. Khan reviews and sends (2.9)". Never write the email address or Ms. Khan's note in the Log.

2.8 Count the roll numbers in the Students tab (Y), and the roll numbers with a Done row in this matter (X). End the run with the skill start-and-end-a-run, with the count "X of Y roll numbers have a progress note". Report the drafts, the Check lines, and each roll number with no draft and the reason.

2.9 (Ms. Khan) She reviews each progress note, reads the Check lines first, writes the name, adjusts it if needed, deletes the Check lines, and sends it.

## The progress note

To: the parent email for that roll number
Subject: Progress note for <Month YYYY>: <roll number>

Check: <only if needed, one line for each check>

Dear parent of [student name],

This is the progress note for <Month YYYY>.

Homework this month:
- <assignment>, due <due date>: submitted / not submitted.

A note from Ms. Khan: <her note, word for word>

Ms. Ayesha Khan, class teacher of Class 7B
