This is the prompt of the scheduled task that runs every Friday at 7:15 in the Class Coordinator project.
The rules for every task are in the project instructions. The rules and steps of T2 are in the knowledge file t2-instructions.md. Ms. Khan's checks are in the knowledge file review-contract.md. This brief only starts one run, and it may narrow those rules, never widen them.

Times: every time in this brief and in the Log is in Pakistan Standard Time (UTC+05:00).

Date check, first: Note today's date. Read no file and no sheet before this check.
- If today is not a Friday, make no drafts, say that the run is late, and stop. Ms. Khan can ask for the notes in the project on any day.
- The term ends on 2026-12-18. Today is the last Friday for notes when the next Friday is in another month, or is after 2026-12-18. If today is not the last Friday for notes, stop.

Outcome: Draft this month's progress note for each student of Class 7B. Done when: every roll number in the Students tab has one draft in Ms. Khan's Gmail, or a Needs Ms. Khan row with the reason; and the Log in the work record has a Completed row for this run.

Context: Use t2-instructions.md, steps 2.2 to 2.8. Read the Updated, Homework, Notes and Students tabs of the working copy. The matter is "Progress notes YYYY-MM" for this month.

Format: One Gmail draft for each roll number, as "The progress note" in t2-instructions.md says.

Constraints: Read the Log first, and add rows as the project instructions say. Only read the working copy. Copy each of Ms. Khan's notes word for word. Never write a note. Never send.

Success (check your own work before you report): one draft for each roll number with a note; each draft is about one student; each lists only this month's assignments, on or before the last Friday for notes; each of Ms. Khan's notes is word for word; a Check line for each unclear homework row.

Evidence to return: first, what you read: each sheet and tab, the number of rows, and the newest date in it. Then: every tool you used; the number of drafts; each Check line, by roll number; each roll number with no draft, and why; the new Log rows.

Stop, and say why, when: the working copy or the work record cannot be opened; the Updated tab is empty, more than seven days before today, or after today; the Homework, Notes or Students tab headings are not as expected; the Notes tab is not for this month; this month's notes already have a Completed row, and Ms. Khan did not ask for the missing notes; today is not the last Friday for notes.
