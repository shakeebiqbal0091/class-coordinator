# Brief for the scheduled task "T4 Dues reminders"

How to use this file: in the Class Coordinator project, make a scheduled task named "T4 Dues reminders" that runs every day at 7:45. Paste only the prompt into it: the text between the lines "Prompt starts" and "Prompt ends". For a dry run, paste the same prompt into a new conversation in the project, then add the test line. The pasted prompt acts as the scheduled run, so on a day that is not a reminder day it stops at the date check.

----- Prompt starts -----

This is the prompt of the scheduled task that runs every day at 7:45 in the Class Coordinator project.
The rules for every task are in the project instructions. The rules and steps of T4 are in the knowledge file t4-instructions.md. Ms. Khan's checks are in the knowledge file review-contract.md. This brief only starts one run, and it may narrow those rules, never widen them. Ms. Khan can also ask "Make the dues reminders" in the project, on any day before the pay-by date.

Times: every time in this brief and in the Log is in Pakistan Standard Time (UTC+05:00).

Date check, first: Note today's date. Read only the dues schedule, nothing else. If no pay-by date is exactly seven days from today, stop.

Outcome: Draft one reminder for each family of Class 7B that has not paid. Done when: each family that has not paid a payment by the pay-by date has one reminder draft in Ms. Khan's Gmail, or a Needs Ms. Khan row that says why; and the Log in the work record has a Completed row for this run.

Context: Use t4-instructions.md, steps 4.1 to 4.9. Read the Updated, Dues and Students tabs of the working copy, and the dues schedule. The matter is "Dues reminders YYYY-MM-DD", with the pay-by date.

Format: One Gmail draft for each family, to the parent only, as "The reminder" in t4-instructions.md says.

Constraints: Read the Log first, and add rows as the project instructions say. Only read the working copy. Write only what the dues schedule says. Never send.

Success (check your own work before you report): one draft for each family that has not paid; each amount matches the dues schedule; a payment already late is named as a second reminder; the total is right; no draft for a family that has paid.

Evidence to return: first, what you read: each sheet and tab, the number of rows, and the newest date in it. Then: every tool you used; the number of families that have not paid and of drafts; each family with no draft, and why; the new Log rows.

Stop, add a Needs Ms. Khan row with the reason, then a Completed row, when: the working copy, the work record or the dues schedule cannot be opened; the Updated tab is empty, more than seven days before today, or after today; the Dues or Students tab headings are not as expected. If the reminders are already made, or the pay-by date has passed, add only a Completed row that says so. If no pay-by date is seven days away (a scheduled run), stop and add no row.

----- Prompt ends -----
