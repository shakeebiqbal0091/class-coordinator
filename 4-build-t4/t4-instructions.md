# T4 instructions: the dues reminders

Use these instructions for T4 of the Class Coordinator for Class 7B: on the reminder day, seven days before each pay-by date in the dues schedule, draft one reminder for each family that has not paid; and when Ms. Khan asks "Make the dues reminders" on a later day before the pay-by date.
The rules for every task are in the project instructions. This file adds the rules and the steps of T4.
Every name and amount in this file is invented.

## Words in this file

- The dues are the term fee. Families pay it in two payments: Payment 1 and Payment 2.
- The pay-by date is the date in the dues schedule by which a payment must be paid. The Dues tab shows it in the column "Pay by".
- The reminder day is seven days before a pay-by date.

## Rules for T4

- The matter is "Dues reminders YYYY-MM-DD", with the pay-by date. Every Log row of T4 has Task "T4" and this matter.
- A family has not paid when a payment with a pay-by date on or before this pay-by date says "No" in the Paid column of the Dues tab. A payment with a later pay-by date is never in the reminder.
- Amounts and dates come only from the dues schedule. Check each amount in the Dues tab against it. If they differ, draft nothing for that family, and add a Needs Ms. Khan row.
- If a Paid cell is empty or unclear, never guess. Draft nothing for that family, and add a Needs Ms. Khan row.
- One reminder for each family. It shows every payment that is not paid, its amount and its pay-by date, and the total. A payment whose pay-by date has passed is named as a second reminder.
- The reminder goes to one email address: the parent email of that roll number, from the Students tab. Never write to a student about money, and never to any other email address.
- Write only what the dues schedule says. Never write about a late fee or any other rule. A question about paying late goes to Ms. Khan.
- The reminder says the date of the records: "On <today>, our records show ...".
- Never write an amount, a name or an email address in the Log. Name the payments only.
- The only request for T4 is "Make the dues reminders". It drafts only for families that have no Done row in this matter.
- After the pay-by date, make no reminders. Add a Completed row that says why, and end.
- The working copy is read-only for you. You add rows only to the Log in the work record.
- Never read email. Only T3 reads email.

## Steps

The step numbers are the same as in the Role Contract. Step 4.10 is Ms. Khan's.

4.1 Check the date. Read only the dues schedule. Find the pay-by date that is seven days from today. In a scheduled run, if there is none, stop, and add no row. When Ms. Khan asks on another day, use the next pay-by date that is today or later. If no pay-by date is left this term, add a Started row and a Completed row ("nothing made: no pay-by date is left this term"), and end.

4.2 Read the Log rows of this matter. Add a Started row: "T4 run <start time> started." If Ms. Khan asked, add: "Ms. Khan asked: Make the dues reminders." (Origin Observed, Source "Ms. Khan, in the project").
- If an earlier run has a Started row and no Completed row, it stopped. Reminders are made in order of roll number. The first family after its last Done row may have a half-made draft: draft nothing for it, and add a Needs Ms. Khan row: "Check your Gmail drafts for this roll number."

4.3 Read the Updated tab of the working copy, as section 3 of the project instructions says. Then read the Dues tab. Check that the headings are Roll number, Payment, Amount (PKR), Pay by and Paid. If not, add a Needs Ms. Khan row ("The Dues tab headings are not as expected"), then a Completed row, and end.

4.4 Check each amount in the Dues tab against the dues schedule.

4.5 Find each family that has not paid, by the rule above. Note each payment, its amount and its pay-by date. If a Paid cell is empty or unclear, or an amount differs from the dues schedule (4.4), draft nothing for that family, and add a Needs Ms. Khan row.
- Draft only for families with no Done row in this matter. A family that got a Needs Ms. Khan row in an earlier run is checked again: if its cell is clear now, draft for it; if not, add a new Needs Ms. Khan row.
- If no family is left to draft, add a Completed row: "T4 run <start time> completed: nothing made, reminders already made, see rows N to M." Say so, and end.

4.6 Read the Students tab. Check that the headings are Roll number, Student email and Parent email. If not, add a Needs Ms. Khan row, then a Completed row, and end. Find the parent email by roll number. If it is missing, draft nothing for that family, and add a Needs Ms. Khan row: "No draft: no parent email."

4.7 Read today's Log rows of the other tasks (T1, T2, T3) for this roll number. If one is a Done row for a draft to the same parent, start the reminder with a Check line: "Check: <run name> saved a <homework email, progress note or reply> to this parent today." Then write the reminder below it, as "The reminder" says.

4.8 Read the Log rows of the matter again. If a Done row for this roll number is there now, draft nothing more for it. If not, save the reminder as a draft in Ms. Khan's Gmail. Add a Done row: the roll number, "Draft saved in Gmail, to the parent: <payments>", and any Check line, Origin Observed, Source "Dues tab; Gmail drafts", Next "Ms. Khan checks the Dues tab, then sends (4.10)".

4.9 Count the Done rows against the families that have not paid. Add a Completed row: "T4 run <start time> completed: X families not paid, Y drafts, Z Needs Ms. Khan." Report the drafts, and each family with no draft and why. Each count and total in the report names its rows, for example "7B-07: PKR 12,000 = Payment 1 + Payment 2, rows 8 and 18 of the Dues tab".

4.10 (Ms. Khan) She checks the Paid cells in the Dues tab again, reads the Check line first, reviews each reminder, writes the name, adjusts it if needed, deletes the Check line, and sends it.

## The reminder

To: the parent email for that roll number
Subject: Reminder: term fee <Payment N, pay by YYYY-MM-DD> (one payment) or <PKR total not paid> (more than one payment), then ": <roll number>"

Check: <only if needed>

Dear parent of [student name],

This is a reminder about the term fee for Class 7B. On <today>, our records show that <Payment N of the term fee, PKR amount, is not paid yet. Please pay it by YYYY-MM-DD.> (one payment)
or, for more than one payment:
On <today>, our records show that these payments of the term fee are not paid yet:
- Payment N, PKR amount, pay by YYYY-MM-DD. (For a pay-by date that has passed: "This is a second reminder for Payment N.")
The total not paid is PKR <total>.

These amounts and dates are in the dues schedule.

If you have a question about paying, please write to me.

Ms. Ayesha Khan, class teacher of Class 7B
